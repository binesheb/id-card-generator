# Project fonts

The ID card renderer is designed to use these supplied font files:

- `Satoshi-Regular.otf` — Satoshi Regular, weight 400
- `Satoshi-Bold.otf` — Satoshi Bold, weight 700
- `VeryVogue-Text.otf` — Very Vogue Text, weight 400

The application references these files from this directory. Keep the filenames unchanged when adding the font binaries to the repository.

The card's variable employee name/designation/body text uses **Satoshi**. Very Vogue Text is reserved for decorative/brand text where required by the final overlay/template.
